# BG EDITWORKS — Site vitrine

Première version du site vitrine de BG EDITWORKS, studio indépendant de post-production.

## Personnalisation rapide

- Les textes et les blocs de la page se trouvent dans `app/page.tsx`.
- Les couleurs et la mise en page se trouvent dans `app/globals.css`.
- Les futurs projets peuvent remplacer les trois cartes « À venir » de la section portfolio.
- Le formulaire et les boutons de contact utilisent `bgeditworks@gmail.com`.
- La marque typographique en haut de page peut être remplacée par le fichier du logo officiel lorsqu'une version transparente sera disponible.

## Lancer le site

Installez les dépendances, puis lancez le mode de développement avec `npm run dev`.

Le site est conçu pour être responsive et peut ensuite être publié chez l'hébergeur de votre choix.
